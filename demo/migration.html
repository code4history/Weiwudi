Writes a 1.1.x-shaped cache into IndexedDB (Weiwudi.mapSetting + Weiwudi_<mapID>.tileCache), 341 tiles (zoom 0-4, one PNG per tile labelled with its z / x / y). Before writing, it deletes this demo's own data (Weiwudi / Weiwudi_* / WeiwudiStore and this demo's service worker registration), so a second run also starts from zero. Databases and service workers of other projects on this origin are left untouched. If a service worker from a previous run is still registered, this step drops it and reloads the page, so that the migration starts from a clean service worker.

Registers the service worker and reads the map back with the old API (Weiwudi.retrieveMap). Migration runs in the background (200 records per batch) while the tiles are being read.

The migration has finished and the buttons above are disabled. To run it again from zero, press "Reset demo data" below.

Old API vs new API

Old (1.1.x) — still runs unchanged
await Weiwudi.registerSW('./sw.js', { scope: './' });
const map = await Weiwudi.registerMap('my_map', {
  type: 'xyz',
  url: 'https://tiles.example.com/{z}/{x}/{y}.png',
  width: 65536, height: 65536, tileSize: 256,
  minZoom: 0, maxZoom: 8,
});
L.tileLayer(map.url).addTo(leaflet);
await map.fetchAll();
const stats = await map.stats();
// { count, size, total, percent }
New (Source API)
await Weiwudi.registerSW('./sw.js', { scope: './' });
const source = await Weiwudi.register({
  kind: 'raster',
  id: 'my_map',
  url: 'https://tiles.example.com/{z}/{x}/{y}.png',
  minZoom: 0, maxZoom: 8,
});
L.tileLayer(source.url).addTo(leaflet);
await source.fetchRange({
  bounds: [139.7, 35.6, 139.8, 35.7],
  minZoom: 0, maxZoom: 8,
});
const stats = await source.stats();
// { count, size, byResource }
How to verify the migration
  1. Press "1. Create a 1.1.x cache"
  2. Press "2. Register SW and migrate" and watch the counters
  3. The map fills with the migrated tiles (each tile shows its z / x / y)
  4. The old databases disappear when the migration finishes
  5. Reload with DevTools → Network → Offline: the tiles still come from the migrated cache

Unregisters this demo's service worker and deletes the Weiwudi IndexedDB databases (Weiwudi / Weiwudi_* / WeiwudiStore), then reloads. Service workers and databases of other projects on this origin are left untouched. Use this before running the demo a second time.

The tile URL recorded in the 1.1.x setting (tiles.example.com) is never contacted: every tile is served from the migrated cache. These are synthetic demo tiles generated in the browser, not map data.
